# [Prismalite](https://prismalite.org)

<img src="Prismalite.png" alt="Prismalite logo, a grey P superimposed upon a green background with a transparent diagonal stripe in the middle." align="right" width="100">

Prismalite is an anyone-welcome Discord server and community led by a team of dedicated gaming creators, and the home of the interactive server bot, PrismaBot.
Formed from co-owners and friends of the [Prismalite Discord server](https://discord.gg/Q5mX9W2WBx), the Prismalite creator team sets out to create a unique dynamic where the streamers are ACTUALLY friends-- something that we feel has been missing from a lot of modern content.


If you're here, it's probably to check out a project. If you stumbled upon the org by accident though, be sure to check out our channels linked above!
